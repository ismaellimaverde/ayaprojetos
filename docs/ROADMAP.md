# Delivery roadmap

0. Discovery: preserve/reconcile both prompts; initial PRD, module/navigation matrix, domain/ERD, metric catalog, architecture and backlog — recorded.
1. Foundation: identity, real database, organization/company/project hierarchy, template instantiation, invitations, MFA, access matrix, audit and layout — executable increment validated by service/integration and browser tests. Production email/recovery/operations remain pending. Delegated company/project administrators have scoped data grants; global user administration remains centralized in v1.
2. Management: goals/OKRs → initiatives → tasks; documents/playbooks; linked ownership; versioned progress; real dashboards with period filters. Add responsibility transfer before account deactivation once task assignments exist.
3. Finance: chart of accounts → cost centers → immutable/auditable entries and reversals → accrual/cash views → budgets and DRE → scenarios. Test retrospective corrections and currency separation.
4. Sales/marketing: contacts → opportunities and stage history → offers/campaigns → attribution and KPIs. Avoid implicit revenue recognition.
5. Connectors: jobs/idempotency/provenance → Meta import → reconciliation → alerts and configurable automation. Requires provider authorization.
6. Expansion: operations, people, customer success, governance, continuity, advanced intelligence and AI.

Next hardening priorities before a production pilot: approved external email, production runtime DB least privilege, backup/restore rehearsal, rate-limit abuse review, policy for recovery of owner MFA, configurable retention and resource-specific authorization as business entities appear. Final product manuals follow implemented behavior, not future promises.
